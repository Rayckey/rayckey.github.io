PLANNING + HUMAN–ROBOT INTERACTION / ICRA 2023

Rearrange Indoor Scenes
for Human–Robot Co-Activity

Rearrange Indoor Scenes for Human–Robot Co-Activity. An optimization-based framework that makes indoor spaces more accessible to robots while preserving the furniture relationships that support human activities.

Co-first authorIEEE ICRA · 2023UCLA
Read the paper ↗Source code ↗Project website ↗

The problem

A room that works for a person may be difficult for a mobile manipulator to navigate. A robot’s footprint can make a narrow passage impassable, and its reach can make an otherwise visible object inaccessible.

This work changes the scene layout itself. It rearranges furniture to improve robot access while retaining functional relationships—such as a chair’s relationship to a desk—that make a room useful to people.

My contribution

I led development of the scene-rearrangement system and implemented hierarchical optimization using adaptive simulated annealing (ASA) and covariance matrix adaptation evolution strategy (CMA-ES).

The optimization combines robot footprint and reachability models with learned spatial relationships, ConceptNet semantics, and functional object groups. I am a co-first author with Zihang Zhao and Ziyuan Jiao.

Balancing two kinds of access

Evaluate

Measure access and assess layout quality.

Spatial co-occurrence is learned from SUNCG, with semantic relationships from ConceptNet. The objective balances navigable space and reachable objects against the human preferences represented by these relationships.

Results

Average improvements reported in the published SUNCG scene evaluation.

+14%Accessible space for the robot.

A human study also assessed the quality of the rearranged scenes. These results come from the paper’s scene evaluation; they are not a physical robot task-completion rate.

Why it matters

Planning depends on both the robot and its environment. Explicitly representing the robot’s embodiment lets us ask a complementary question: how should a space change so that a robot can work alongside people?

This project is part of my broader work on embodiment-aware task realization, alongside mobile manipulation, tool-use planning, and robot learning.
